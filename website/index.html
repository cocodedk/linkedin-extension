LinkedIn Lead Collection

LinkedIn Extension helps you collect and evaluate lead data from LinkedIn search results directly in your browser. Fast, private, and developer-friendly.

Download Extension

Features

  • Collect lead data from LinkedIn search result pages
  • Evaluate and filter leads based on configurable criteria
  • Export collected lead data for further processing
  • Full test suite — Vitest (unit) + Playwright (integration)
  • Offline operation — no data sent to external servers

Installation

  1. Download the latest linkedin-extension.zip and extract it.
  2. Open Chrome and navigate to chrome://extensions/.
  3. Enable Developer mode (top-right toggle).
  4. Click Load unpacked and select the chrome/ folder.

Build from Source

git clone https://github.com/cocodedk/linkedin-extension.git
cd linkedin-extension
npm ci
npm test          # Run unit tests
npm run lint      # Lint code

Architecture

linkedin-extension/
├── chrome/          ← Extension source (MV3)
├── tests/           ← Vitest unit tests
├── test-extension/  ← Playwright helpers
└── website/         ← This site

Tech stack: JavaScript ES modules · Chrome MV3 · Vitest · Playwright · ESLint · Prettier
